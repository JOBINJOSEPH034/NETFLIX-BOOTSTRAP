# 🎬 Netflix Clone  

A **Netflix Clone** built using **HTML, CSS, and Bootstrap** to replicate the user interface of the popular streaming platform. This static website project focuses on responsive design, UI aesthetics, and modern front-end styling techniques.  

##  Features  
✅ **Homepage UI** – A sleek and modern design inspired by Netflix.  
✅ **Responsive Layout** – Works seamlessly on all devices.  
✅ **Hover Effects & Animations** – Enhances the user experience.  
✅ **Bootstrap Grid System** – Ensures a structured and adaptive layout.  

## 🛠️ Technologies Used  
- **HTML5** – For structuring the web pages.  
- **CSS3** – For styling and animations.  
- **Bootstrap** – For responsive design and grid layout.
